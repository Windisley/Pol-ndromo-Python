# Verificador de Palíndromos em Python

Este projeto é um simples **verificador de palíndromos** que verifica se uma palavra ou frase fornecida pelo usuário é um palíndromo. Um **palíndromo** é uma palavra, frase, número ou qualquer sequência de caracteres que pode ser lida da mesma maneira de trás para frente (ignorando espaços e pontuação).

## Funcionalidade

- O código solicita ao usuário que insira uma palavra ou frase.
- Ele então verifica se a palavra ou frase é um palíndromo.
- A verificação leva em consideração as letras minúsculas, e a string original é comparada com sua versão invertida.
- Se a entrada for um palíndromo, o código imprime a mensagem: "Essa frase é um palíndromo".
- Caso contrário, a mensagem será: "Essa frase não é um palíndromo".
- O código também imprime a frase original e sua versão reversa.

O programa solicitará que você insira uma palavra ou frase. Após a inserção, ele retornará se é um palíndromo ou não, e mostrará a versão invertida da palavra/frase.

Informe a palavra: arara
